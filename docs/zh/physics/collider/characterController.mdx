角色控制器（[CharacterController](/apis/core/#CharacterController)）是一种特殊的碰撞器组件，专门用于处理角色的物理运动。它提供了专门的移动算法和碰撞检测，能够处理台阶、斜坡等复杂地形，特别适合第一人称或第三人称游戏中的角色控制。

## 与刚体的区别

角色控制器和[刚体](/docs/physics/collider/rigidbody)虽然都可以实现物体的移动，但它们有着显著的区别：

| 特性 | 角色控制器 | 刚体 |
|------|------------|------------|
| 移动方式 | 通过 `move()` 方法直接控制位移 | 通过施加力或设置速度来移动 |
| 碰撞响应 | 手动处理碰撞响应，自动处理台阶和斜坡 | 基于物理模拟的碰撞响应 |
| 重力处理 | `simpleMove()` 应用场景重力，`move()` 使用传入的位移 | 自动应用场景重力 |
| 形状 | 内置的胶囊体或盒，由 `geometry` 选择 | 所在实体及子实体上的任意碰撞器组件 |
| 适用场景 | 角色控制、第一/第三人称游戏 | 物理模拟、刚体运动 |

<Callout type="positive">
选择建议：
- 如果需要精确控制角色的移动和碰撞响应，使用角色控制器
- 如果需要真实的物理模拟效果，使用刚体
</Callout>

## 使用方法

1. 选中目标实体，并在检查器中点击添加组件按钮，添加 CharacterController 组件。

<Image src="https://mdn.alipayobjects.com/huamei_3zduhr/afts/img/A*nEMXRKiqpy8AAAAAAAAAAAAAesJ_AQ/original" />

2. 选择控制器的 `geometry`，并设置其尺寸（胶囊体用 `radius` 和 `height`，盒用 `size`）和 `center`，使其与角色的外形尽量匹配。

<Callout type="positive">
角色控制器自带几何形状，不使用其他碰撞器组件，也不会被任何刚体拥有。通常建议角色使用默认的胶囊体。
</Callout>

3. 根据需要设置控制器的属性，各属性的含义和作用请参考下文。

## 属性说明

### 几何形状
| 属性 | 描述 | 默认值 |
| ---- | ---- | ------ |
| [**geometry**](/apis/core/#CharacterController-geometry) | `CharacterControllerGeometry.Capsule`（沿 `upDirection` 的胶囊体）或 `CharacterControllerGeometry.Box`（轴对齐的盒） | Capsule |
| [**radius**](/apis/core/#CharacterController-radius) | 胶囊体在实体局部空间中的半径 | 0.5 |
| [**height**](/apis/core/#CharacterController-height) | 胶囊总高度，包含两端半球。缩放后的高度必须大于缩放后的直径。 | 2 |
| [**size**](/apis/core/#CharacterController-size) | 盒在实体局部空间中的尺寸 | (1, 1, 1) |
| [**center**](/apis/core/#Collider-center) | 几何形状在实体局部空间中的中心 | (0, 0, 0) |

几何形状跟随实体的世界缩放。继承自 Collider 的 `rotation` 对角色控制器不生效。

### 继承自 Collider 的属性
| 属性 | 描述 | 默认值 |
| ---- | ---- | ------ |
| [**contactOffset**](/apis/core/#CharacterController-contactOffset) | 接触偏移，必须大于 0，否则抛出异常 | 0.02 |
| [**collisionLayer**](/apis/core/#Collider-collisionLayer) | 控制器所属的碰撞层 | Layer.Layer0 |
| [**material**](/apis/core/#Collider-material) | 物理材质，`null` 表示共享默认材质 | null |
| [**isTrigger**](/apis/core/#CharacterController-isTrigger) | 始终为 false，设置为 true 会抛出异常 | false |

### 特有属性
| 属性 | 描述 | 默认值 |
| ---- | ---- | ------ |
| [**detectCollisions**](/apis/core/#CharacterController-detectCollisions) | 是否阻挡撞向本控制器的刚体和其他角色控制器。设为 `false` 也会关闭触发器交互。本控制器调用 `move()` 时仍检测障碍，查询可见性仍由 `isSceneQuery` 控制。 | true |
| [**stepOffset**](/apis/core/#CharacterController-stepOffset) | 请求的台阶高度，使用世界单位。PhysX 将实际跨越高度限制在控制器缩放后的高度以内，属性保留请求值。有限负值会限制为 0。 | 0.5 |
| [**climbingMode**](/apis/core/#CharacterController-climbingMode) | 胶囊的跨台阶方式。`Easy` 允许胶囊依靠弧面跨上高于 `stepOffset` 的台阶，`Constrained` 限制这一行为。 | Constrained |
| [**slopeLimit**](/apis/core/#CharacterController-slopeLimit) | 角色可以行走的最大斜坡角度（度）。<ul><li>超过此角度的斜面将被视为不可行走的墙壁</li><li>影响角色的爬坡能力</li></ul> | 45° |
| [**invisibleWallHeight**](/apis/core/#CharacterController-invisibleWallHeight) | 不可行走的网格和地形三角形周围的隐形墙高度，使用世界单位。0 表示关闭隐形墙。 | 0 |
| [**maxJumpHeight**](/apis/core/#CharacterController-maxJumpHeight) | 启用隐形墙时沿角色上方向的反向扩展的搜索距离，使用世界单位。可设为足以覆盖角色跳跃高度的距离。 | 0 |
| [**nonWalkableMode**](/apis/core/#CharacterController-nonWalkableMode) | 定义如何处理不可行走的表面。<ul><li>PreventClimbing：阻止角色攀爬不可行走的斜坡，但不会强制其他移动（默认）</li><li>PreventClimbingAndForceSliding：阻止角色攀爬不可行走的斜坡，并强制角色沿斜坡滑下</li></ul> | PreventClimbing |
| [**upDirection**](/apis/core/#CharacterController-upDirection) | 定义角色的向上方向。默认为 (0, 1, 0)，即世界空间的 Y 轴向上。影响移动和碰撞检测的方向判定 | (0, 1, 0) |

## 场景移动设置

`scene.physics.characterControllerPreciseSweeps` 默认开启精确扫掠。将 `scene.physics.characterControllerSlideOnCeiling` 设为 `false`，向上跳到倾斜天花板时会停止沿斜面滑移。

移动彼此重叠的控制器前，调用一次 `scene.physics.computeCharacterControllerInteractions()`。该方法按场景碰撞规则计算分离量，各控制器在下一次 `move()` 时应用各自的分离量。

## 公开方法

| 方法名 | 描述 |
| ---- | ---- |
| [**move**](/apis/core/#CharacterController-move) | 移动角色控制器，并立即把结果写入实体的世界坐标。返回一个碰撞标志值，标识碰撞状态；控制器不在场景中时返回 0。<ul><li>displacement：移动向量</li><li>minDist：结束扫掠的剩余距离，默认 0</li><li>elapsedTime：距上次移动的秒数，默认使用场景的固定步长</li></ul> |
| [**simpleMove(speed, elapsedTime?)**](/apis/core/#CharacterController-simpleMove) | 以给定世界速度在垂直于 `upDirection` 的平面移动，并沿该轴应用重力。返回本次移动是否接地。省略时长时使用场景的固定步长。 |
| [**getFootPosition(out)**](/apis/core/#CharacterController-getFootPosition) | 写出包含接触偏移的脚底世界坐标。 |
| [**setFootPosition(position)**](/apis/core/#CharacterController-setFootPosition) | 瞬移控制器，让脚底到达指定的世界坐标。 |
| [**resize(height)**](/apis/core/#CharacterController-resize) | 设置局部空间中的总高，保持脚底位置不动。调高前应先检查头顶空间。 |

通过 `isGrounded` 或 `collisionFlags` 读取上次移动的接触状态，通过 `getVelocity(out)` 获取其实际世界速度。场景查询同帧可见新位置。

在第四个参数传入 `ControllerMoveFilter` 可以限制本次移动的碰撞范围。`layerMask` 选择碰撞层，`exclude` 排除指定碰撞体，也可以排除其他角色控制器。场景碰撞矩阵和逐对忽略规则仍然生效。

在移动实体的脚本中实现 `onControllerColliderHit(hit)`，即可收到控制器扫掠产生的接触。回调在实体坐标写入后、`move` 返回前执行，一次移动可能产生多次回调。数据包括命中的碰撞体、世界坐标下的接触点和法线，以及本次扫掠区段的方向和长度。需要跨回调使用时请复制。

实现推动逻辑时，可以用接触数据向 `hit.collider.attachedRigidbody` 施加力或冲量。站在移动平台上时，`move` 会随支撑点的平移和旋转更新位置，实体朝向保持不变。

场景的 `physics.characterControllerOverlapRecovery` 默认为 `true`，让控制器在移动时尝试脱离与静态碰撞体的重叠。

角色控制器不支持 `getClosestPoint`，调用时返回 -1。

### 碰撞标志说明

移动函数 `move()` 会返回一个碰撞标志值，用于表示角色控制器与环境的碰撞状态。这些标志可以通过按位与运算(&)来检测：

| 标志名称 | 值 | 说明 |
|---------|----|----|
| None | 0 | 没有发生任何碰撞 |
| Sides | 1 | 与侧面发生碰撞 |
| Up | 2 | 与上方发生碰撞（如天花板） |
| Down | 4 | 与下方发生碰撞（如地面） |

## 脚本使用

### 基础配置
```typescript
// 新建控制器默认使用胶囊体。
const controller = entity.addComponent(CharacterController);
controller.radius = 0.5;
controller.height = 2;
controller.center = new Vector3(0, 1, 0);

// 改用盒体时，设置其沿局部轴的完整尺寸。
// controller.geometry = CharacterControllerGeometry.Box;
// controller.size = new Vector3(1, 2, 1);

// 配置控制器属性
controller.stepOffset = 0.5;      // 设置台阶高度
controller.slopeLimit = 45;       // 设置最大可行走斜坡角度
controller.upDirection = new Vector3(0, 1, 0); // 设置向上方向
```

### 使用移动函数
```typescript
class CharacterMovement extends Script {
  private _controller: CharacterController;
  private readonly _displacement = new Vector3();
  private _verticalSpeed = 0;
  private _jumpRequested = false;

  onAwake() {
    this._controller = this.entity.getComponent(CharacterController);
  }

  onUpdate() {
    this._jumpRequested ||= this.engine.inputManager.isKeyDown(Keys.Space);
  }

  onPhysicsUpdate(dt: number) {
    const input = this.engine.inputManager;
    const physics = this.scene.physics;
    const x = Number(input.isKeyHeldDown(Keys.KeyD)) - Number(input.isKeyHeldDown(Keys.KeyA));
    const z = Number(input.isKeyHeldDown(Keys.KeyW)) - Number(input.isKeyHeldDown(Keys.KeyS));
    const displacement = this._displacement.set(x, 0, z).normalize().scale(5 * dt);

    if (this._jumpRequested && this._controller.isGrounded) {
      this._verticalSpeed = 5;
    }
    this._jumpRequested = false;
    this._verticalSpeed += physics.gravity.y * dt;
    displacement.y = this._verticalSpeed * dt;

    const contacts = this._controller.move(displacement, 0, dt);
    if (contacts & (ControllerCollisionFlag.Down | ControllerCollisionFlag.Up)) {
      this._verticalSpeed = 0;
    }
  }
}
```

使用示例：
```typescript
const flags = controller.move(displacement, 0, deltaTime);

// 检查是否接触地面
if (flags & ControllerCollisionFlag.Down) {
    // 角色在地面上
    this._isGrounded = true;
}

// 检查是否撞到天花板
if (flags & ControllerCollisionFlag.Up) {
    // 角色撞到头部
    this._velocity.y = 0;
}

// 检查是否撞到墙壁
if (flags & ControllerCollisionFlag.Sides) {
    // 角色撞到墙壁
    this._handleWallCollision();
}

// 可以同时检查多个标志
if ((flags & ControllerCollisionFlag.Down) && 
    (flags & ControllerCollisionFlag.Sides)) {
    // 角色同时接触地面和墙壁
}
```

### 斜坡/台阶行走

1. **斜坡行走**
```typescript
// 通过设置 slopeLimit 控制可行走的斜坡角度
controller.slopeLimit = 60; // 允许更陡的斜坡

// 设置不可行走斜面的处理方式
controller.nonWalkableMode = ControllerNonWalkableMode.PreventClimbingAndForceSliding; // 在太陡的斜面上会滑下
```

2. **台阶行走调整**
```typescript
// 调整 stepOffset 来控制可跨越的台阶高度
controller.stepOffset = 0.3; // 较低的台阶
controller.stepOffset = 0.5; // 较高的台阶
```

## 限制和注意事项

1. **几何形状**
   - 控制器只有一个内置的胶囊体或盒；实体上的其他碰撞器组件是独立的碰撞器
   - 建议角色使用胶囊体
   - 控制器不能作为触发器，也不支持 `getClosestPoint`

2. **性能考虑**
   - 每个角色控制器都会占用一定的物理计算资源
   - 建议在场景中控制角色控制器的数量
